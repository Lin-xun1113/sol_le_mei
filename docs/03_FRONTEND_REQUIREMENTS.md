## 页面结构

### 1. 首页 `/` (Landing + Dashboard)

**功能**:
- 未连接钱包: 显示项目介绍 + 连接钱包按钮
- 已连接但未注册: 显示注册入口
- 已注册: 显示个人 Dashboard

**Dashboard 核心元素**:
```
┌─────────────────────────────────────────────────────┐
│                    Sol了没 Dashboard                 │
├─────────────────────────────────────────────────────┤
│                                                     │
│   ┌─────────────────────────────────────────────┐   │
│   │            💓 生存状态                        │   │
│   │                                             │   │
│   │   状态: ✅ 活着 / ❌ 已死亡                   │   │
│   │   模式: 🛡️ 安全模式 / 🦅 吃席模式           │   │
│   │   RIP 收到: 12 次                           │   │
│   │                                             │   │
│   │   ⏱️ 距离下次签到截止: 23:45:12              │   │
│   │   ████████████████░░░░ 72%                  │   │
│   │                                             │   │
│   │   [💓 立即签到]                              │   │
│   └─────────────────────────────────────────────┘   │
│                                                     │
│   ┌─────────────────────────────────────────────┐   │
│   │            💰 资金保险库                      │   │
│   │                                             │   │
│   │   当前余额: 2.5 SOL                         │   │
│   │   受益人: 8xK2...3nFp                       │   │
│   │                                             │   │
│   │   [存入资金] [修改受益人]                     │   │
│   └─────────────────────────────────────────────┘   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**关键交互**:
1. **签到按钮** - 调用 `heartbeat` 指令
2. **存入资金** - 弹窗输入金额，调用 `deposit`
3. **倒计时** - 实时计算 `lastPulse + timeoutSeconds - now`

### 2. 注册页 `/register`

**表单字段**:
| 字段       | 类型         | 说明                                       |
| ---------- | ------------ | ------------------------------------------ |
| 超时时间   | Select       | 预设选项: 1分钟(测试), 24小时, 48小时, 7天 |
| 模式       | Radio        | 安全模式 / 吃席模式                        |
| 受益人地址 | Input + 验证 | Solana 地址格式校验                        |
| 初始存款   | Input (可选) | 注册后立即存入                             |

**模式说明 UI**:
```
🛡️ 安全模式
  如果你断签，资金将转给你的受益人。
  适合: 资产保全、遗嘱规划

🦅 吃席模式
  如果你断签，资金进入公共池，任何人可以捡漏！
  你将获得 50%，公共池获得 50%。
  适合: 冒险玩家、Degen
```

### 3. 墓地页 `/graveyard`

**功能**: 展示所有"已死亡"且有余额可捡漏的用户

**列表项结构**:
```
┌───────────────────────────────────────────────────────┐
│ 💀 8xK2...3nFp                                        │
│                                                       │
│  死亡时间: 2024-01-24 10:30                           │
│  遗产金额: 1.5 SOL                                    │
│  收到 RIP: 5 次                                       │
│                                                       │
│  [🦅 捡漏]                                            │
└───────────────────────────────────────────────────────┘
```

**数据获取**: 
- 需要遍历链上 UserProfile 账户
- 筛选条件: `isDead == true && mode == 1 && vault余额 > 0`
- 推荐使用 Helius 或 getProgramAccounts

## 组件清单

### 必须组件

| 组件              | 说明                            |
| ----------------- | ------------------------------- |
| `WalletProvider`  | 钱包连接 Provider               |
| `ConnectButton`   | 连接钱包按钮                    |
| `CountdownTimer`  | 倒计时组件 (距离签到截止)       |
| `HeartbeatButton` | 签到按钮 (带 loading、成功动画) |
| `VaultCard`       | 显示 Vault 余额和操作           |
| `StatusBadge`     | 状态徽章 (活着/死亡/未注册)     |
| `GraveyardList`   | 死者列表                        |
| `RipForm`         | 发送 RIP 表单                   |
| `RegisterForm`    | 注册表单                        |

### 可选组件

| 组件                | 说明                      |
| ------------------- | ------------------------- |
| `Leaderboard`       | 生存排行榜 (连续签到天数) |
| `RipHistory`        | RIP 发送/接收历史         |
| `NotificationToast` | 交易成功/失败通知         |

## 设计风格

### 主题
- **赛博朋克墓地风格** 或 **极简心电图风格**
- 暗色主题为主
- 强调红色 (心跳)、绿色 (活着)、灰色 (死亡)

### 配色参考
```css
--color-alive: #22c55e;    /* 绿色 - 活着 */
--color-dead: #ef4444;     /* 红色 - 死亡 */
--color-warning: #f59e0b;  /* 黄色 - 即将超时 */
--color-accent: #8b5cf6;   /* 紫色 - 强调色 */
--color-bg: #0f0f0f;       /* 深黑背景 */
--color-card: #1a1a1a;     /* 卡片背景 */
```

### 动画
- 心跳动画 (签到按钮)
- 倒计时闪烁 (最后 1 小时)
- 死亡时的"碎裂"效果
